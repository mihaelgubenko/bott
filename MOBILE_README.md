# 📱 HR-Психоаналитик Бот - Мобильная версия

Оптимизированная версия HR-психоаналитического бота для мобильных устройств.

## 🎯 Особенности мобильной версии

### ✅ Оптимизации для мобильных устройств:
- **Упрощенный интерфейс** - короткие сообщения, быстрые ответы
- **Оптимизированные промпты** - меньше текста, больше эмпатии
- **Быстрая загрузка** - минимальные зависимости
- **Адаптивные ответы** - подстраиваются под размер экрана
- **Упрощенная навигация** - меньше команд, больше естественного общения

### 🧠 ИИ-возможности:
- **Анализ эмоций** - понимает настроение пользователя
- **A/B тестирование** - автоматически улучшает ответы
- **Персонализация** - адаптируется под каждого пользователя
- **Контекстная память** - помнит весь разговор

## 🚀 Быстрый запуск

### 1. Установка зависимостей:
```bash
pip install -r mobile_requirements.txt
```

### 2. Настройка переменных окружения:
Создайте `.env` файл:
```
BOT_TOKEN=your_telegram_bot_token
OPENAI_API_KEY=your_openai_api_key
PAYMENT_TOKEN=your_payment_token  # опционально
```

### 3. Запуск бота:
```bash
python new_hr_bot.py
```
