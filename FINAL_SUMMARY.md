## 📱 Созданные файлы ботов

### 1. **Простая мобильная версия** (рекомендуется)
- **Файл:** `simple_mobile_bot.py`
- **Время запуска:** 2 минуты
- **Сложность:** Низкая
- **Функции:** Базовые (психологическая поддержка, анализ личности)

### 2. **Полная мобильная версия**
- **Файл:** `new_hr_bot.py`
- **Время запуска:** 5 минут
- **Сложность:** Средняя
- **Функции:** Расширенные (A/B тестирование, анализ эмоций)

### 3. **Оригинальная версия**
- **Файл:** `hr_psychoanalyst_bot.py`

- **Сложность:** Высокая
- **Функции:** Полные (все возможности)

## 🚀 Быстрый запуск

### Вариант 1: Автоматический запуск
```bash
python quick_start.py
```

### Вариант 2: Ручной запуск
```bash
# 1. Установите зависимости
pip install -r mobile_requirements.txt

# 2. Настройте .env файл
echo "BOT_TOKEN=your_token_here" > .env
echo "OPENAI_API_KEY=your_key_here" >> .env

# 3. Запустите бота
python simple_mobile_bot.py
```

### Вариант 3: Создание кастомного бота
```bash
python create_new_bot.py
```

## 🔧 Настройка

### 1. Переменные окружения (.env):
```env
BOT_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here
PAYMENT_TOKEN=your_payment_token_here
```

### 2. Зависимости:
```bash
# Для простой версии
pip install -r mobile_requirements.txt

# Для полной версии
pip install -r requirements.txt
```
