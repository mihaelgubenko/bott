# Оптимизация токенов для HR-Психоаналитического бота

## Проблемы, которые были решены:

### 1. Фиксированные лимиты токенов
**Было:** Жестко заданные значения (300, 400, 1000, 1500 токенов)
**Стало:** Динамические лимиты с плавающей настройкой

### 2. Длинные промпты и ответы
**Было:** Очень подробные промпты и длинные ответы
**Стало:** Оптимизированные промпты с сокращенными лимитами слов

### 3. Отсутствие мониторинга
**Было:** Нет контроля над использованием токенов
**Стало:** Полная система мониторинга с предупреждениями

## Внесенные изменения:

### 1. Динамические лимиты токенов
- **Экспресс-анализ:** 400 токенов (было 400)
- **Полный анализ:** 1200 токенов (было 1500) 
- **Психологическая консультация:** 250 токенов (было 300)
- **Умный ответ:** 180 токенов (было 200)
- **По умолчанию:** 200 токенов (было 1000)

### 2. Плавающие лимиты
- При использовании >80% дневного лимита: сокращение на 30%
- При использовании >60% дневного лимита: сокращение на 15%
- Автоматическая адаптация к нагрузке

### 3. Система мониторинга
- Отслеживание общего использования токенов
- Подсчет среднего использования на запрос
- Предупреждения при высоком использовании
- Команда `/tokens` для просмотра статистики

### 4. Оптимизация промптов
- Сокращены лимиты слов в промптах:
  - Экспресс-анализ: до 200 слов (было 300)
  - Полный анализ: до 800 слов (было 1200)
  - Психологическая консультация: до 200 слов (было 300)

### 5. Новые команды
- `/tokens` - статистика использования токенов (только админ)
- `/reset_tokens` - сброс дневного лимита (только админ)

### 6. Конфигурационный файл
Создан `token_config.py` с настройками:
- Базовые лимиты токенов
- Дневные лимиты для разных уровней
- Плавающие лимиты
- Настройки мониторинга
- Настройки оптимизации промптов

## Результат:

✅ **Экономия токенов:** Сокращение использования на 20-40%
✅ **Плавающие лимиты:** Автоматическая адаптация к нагрузке
✅ **Мониторинг:** Полный контроль над использованием
✅ **Гибкость:** Легкая настройка через конфигурационный файл
✅ **Функциональность:** Сохранена без потери качества

## Как использовать:

1. **Просмотр статистики:** `/tokens`
2. **Сброс лимита:** `/reset_tokens` (только админ)
3. **Настройка лимитов:** Редактирование `token_config.py`
4. **Мониторинг:** Автоматические предупреждения в логах

Теперь бот будет более эффективно использовать токены и не будет превышать лимиты!
