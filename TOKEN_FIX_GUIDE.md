# 🔧 Руководство по исправлению проблемы с токенами в MindScanBot

## 🚨 Проблема
Диалоги в MindScanBot обрываются на середине из-за превышения лимитов токенов OpenAI API.

## ✅ Реализованные исправления

### 1. **Умное управление токенами**
- Увеличены лимиты `max_tokens` для всех типов ответов
- Добавлен параметр `ensure_completion=True` для гарантии завершения ответов
- Автоматическое увеличение лимита токенов при необходимости

### 2. **Оптимизация контекста**
- Сокращено количество хранимых сообщений с 15 до 10
- Добавлена функция `smart_context_reduction()` для умного сокращения контекста
- Автоматическое сокращение длинных сообщений до 200 символов

### 3. **Мониторинг токенов**
- Создан модуль `token_monitor.py` для отслеживания использования токенов
- Автоматическая проверка размера промптов перед отправкой
- Логирование использования токенов и стоимости

### 4. **Умная разбивка ответов**
- Функция `send_long_response()` для разбивки длинных ответов на части
- Разбивка по предложениям, а не по символам
- Автоматические префиксы для продолжения

### 5. **Защита от обрыва**
- Проверка завершения ответов (точки, восклицательные знаки, эмодзи)
- Автоматическое добавление "..." при обрыве
- Предупреждения в промптах о необходимости завершения

## 📝 Инструкции по использованию

### Для разработчиков:
1. Всегда используйте `ensure_completion=True` для важных ответов
2. Передавайте `user_id` и `prompt_type` в `get_ai_response()`
3. Мониторьте логи на предмет предупреждений о токенах

### Для пользователей:
1. Если ответ обрывается, попробуйте переформулировать вопрос
2. Используйте команду `/reset` для очистки контекста
3. При длинных диалогах периодически перезапускайте бота
