# 🚀 Быстрый старт - Создание нового бота

## ✅ Да, можно создать новый файл проекта бота!

У вас есть **3 готовых варианта** для создания нового бота:

## 📱 Вариант 1: Простая мобильная версия (рекомендуется)

```bash
# 1. Установите зависимости
pip install -r mobile_requirements.txt

# 2. Настройте .env файл
echo "BOT_TOKEN=your_token_here" > .env
echo "OPENAI_API_KEY=your_key_here" >> .env

# 3. Запустите бота
python simple_mobile_bot.py
```

**Особенности:**
- ✅ Быстрый запуск (2 минуты)
- ✅ Минимум зависимостей
- ✅ Оптимизирован для мобильных
- ✅ Простой интерфейс

## 📱 Вариант 2: Полная мобильная версия

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Настройте .env файл
echo "BOT_TOKEN=your_token_here" > .env
echo "OPENAI_API_KEY=your_key_here" >> .env

# 3. Запустите бота
python new_hr_bot.py
```

**Особенности:**
- ✅ Все функции оригинального бота
- ✅ Оптимизирован для мобильных
- ✅ A/B тестирование
- ✅ Анализ эмоций

## 🤖 Вариант 3: Автоматическое создание

```bash
# 1. Запустите генератор
python create_new_bot.py

# 2. Следуйте инструкциям
# 3. Перейдите в созданную директорию
# 4. Запустите бота
```

**Особенности:**
- ✅ Полная кастомизация
- ✅ Автоматическая настройка
- ✅ Docker поддержка
- ✅ Готовые конфигурации

## 📊 Сравнение вариантов

| Критерий | Простая | Полная | Автосоздание |
|----------|---------|--------|--------------|
| **Время запуска** | 2 мин | 5 мин | 10 мин |
| **Сложность** | Низкая | Средняя | Высокая |
| **Функции** | Базовые | Расширенные | Полные |
| **Кастомизация** | Ограниченная | Средняя | Полная |

## 🔧 Настройка переменных окружения

Создайте файл `.env`:

```env
# Обязательные переменные
BOT_TOKEN=your_telegram_bot_token_here
OPENAI_API_KEY=your_openai_api_key_here

# Опциональные переменные
PAYMENT_TOKEN=your_payment_token_here
DEBUG=False
LOG_LEVEL=INFO
```
