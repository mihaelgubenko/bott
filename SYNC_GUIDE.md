# 🔄 Руководство по синхронизации чатов HR-Психоаналитика

## 📋 Обзор

Система синхронизации позволяет переносить данные чатов между разными устройствами и средами. Поддерживаются несколько способов синхронизации:

- **Экспорт/Импорт файлов** - ручная синхронизация через файлы
- **Веб-интерфейс** - управление через браузер
- **Облачная синхронизация** - автоматическая синхронизация с облачными сервисами
- **Telegram команды** - управление через бота

## 🚀 Быстрый старт

### 1. Экспорт данных

**Через Telegram бота:**
```
/export json
```

**Через веб-интерфейс:**
1. Откройте веб-интерфейс: `http://localhost:5000`
2. Перейдите в раздел "Экспорт"
3. Нажмите "Скачать JSON" или "Скачать CSV"

**Через Python:**
```python
from data_sync import get_sync_manager

sync_manager = get_sync_manager()
file_path = sync_manager.export_all_data('json')
print(f"Данные экспортированы в: {file_path}")
```

### 2. Импорт данных

**Через Telegram бота:**
1. Отправьте команду `/import`
2. Прикрепите файл экспорта
3. Дождитесь завершения импорта

**Через веб-интерфейс:**
1. Перейдите в раздел "Импорт"
2. Выберите файл экспорта
3. Нажмите "Импортировать данные"

**Через Python:**
```python
from data_sync import get_sync_manager

sync_manager = get_sync_manager()
result = sync_manager.import_data('export_file.json', merge_mode=True)
print(f"Импортировано: {result}")
```

## 📁 Форматы файлов

### JSON формат
- **Полная структура данных** с метаинформацией
- **Рекомендуется** для полной синхронизации
- **Содержит:** анализы, A/B тесты, назначения вариантов
- **Размер:** обычно 1-10 МБ

### CSV формат
- **Табличный формат** для анализа в Excel
- **Подходит** для просмотра и анализа данных
- **Содержит:** только основные данные анализов
- **Размер:** обычно 100 КБ - 1 МБ

### Запуск веб-интерфейса

- **📥 Импорт данных** - загрузка и импорт файлов

## 🤖 Telegram команды

### Команды для администраторов

| Команда | Описание | Пример |
|---------|----------|--------|
| `/export [формат]` | Экспорт данных | `/export json` |
| `/import` | Импорт данных | `/import` |
| `/sync` | Информация о синхронизации | `/sync` |

```bash
/import

# Информация о синхронизации
/sync
```

## ☁️ Облачная синхронизация

### Настройка Google Drive

```python
from cloud_sync import get_cloud_sync_manager

cloud_sync = get_cloud_sync_manager()
cloud_sync.setup_google_drive('credentials.json')
cloud_sync.enable_auto_sync(24)  # каждые 24 часа
```

### Настройка Dropbox

```python
from cloud_sync import get_cloud_sync_manager

cloud_sync = get_cloud_sync_manager()
cloud_sync.setup_dropbox('your_access_token')
cloud_sync.enable_auto_sync(12)  # каждые 12 часов
```

### Автоматическая синхронизация

```python
# Ручная синхронизация
result = cloud_sync.manual_sync()

# Проверка статуса
status = cloud_sync.get_sync_status()
```

## 🛠️ Устранение неполадок

### Частые проблемы

**1. Ошибка импорта файла**
- Проверьте формат файла (JSON/CSV)
- Убедитесь, что файл не поврежден
- Проверьте размер файла (максимум 16 МБ)

**2. Веб-интерфейс не запускается**
- Проверьте установку Flask: `pip install Flask`
- Убедитесь, что порт 5000 свободен
- Проверьте права доступа к файлам

**3. Облачная синхронизация не работает**
- Проверьте настройки API ключей
- Убедитесь в правильности путей к файлам
- Проверьте интернет-соединение

## 🔒 Безопасность

### Рекомендации

- **Регулярно создавайте резервные копии** данных
- **Не передавайте файлы экспорта** через незащищенные каналы
- **Используйте HTTPS** для веб-интерфейса в продакшене
- **Ограничьте доступ** к административным командам
