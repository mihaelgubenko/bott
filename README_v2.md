### 🔧 Новые возможности

#### 1. Автоматическое управление токенами
- **Предсказание переполнения** - система заранее определяет, когда ответ может обрезаться
- **Адаптивные лимиты** - лимиты токенов подстраиваются под каждого пользователя
- **Умное сжатие контекста** - сохранение важной информации при сжатии диалогов
- **Автоматическое продолжение** - если ответ обрезался, система автоматически его продолжает

#### 2. Интеллектуальное кэширование
- **Кэш ответов** - повторные запросы обрабатываются мгновенно
- **Адаптивный TTL** - время жизни кэша зависит от типа ответа
- **LRU алгоритм** - автоматическое удаление старых записей
- **Статистика использования** - мониторинг эффективности кэша

#### 3. Адаптивные промпты
- **Множественные варианты** - разные версии промптов для разных ситуаций
- **Автоматический выбор** - система сама выбирает оптимальный промпт
- **A/B тестирование** - автоматическое тестирование эффективности промптов
- **Персонализация** - промпты адаптируются под предпочтения пользователя

#### 4. Мониторинг и оптимизация
- **Отслеживание паттернов** - анализ поведения пользователей
- **Автоматическая оптимизация** - система сама улучшает свою работу
- **Предупреждения** - уведомления о проблемах
- **Аналитика** - детальная статистика работы системы

### 🚀 Запуск

1. **Установка зависимостей:**
```bash
pip install -r requirements_v2.txt
```

2. **Настройка переменных окружения:**
```bash
export BOT_TOKEN="your_telegram_bot_token"
export OPENAI_API_KEY="your_openai_api_key"
export PAYMENT_TOKEN="your_payment_token"  # опционально
```

3. **Запуск бота:**
```bash
python hr_psychoanalyst_bot_v2.py
```

### 🔍 Решение проблем с токенами

#### Проблема: Ответы обрезаются
**Решение:** Система автоматически:
1. Предсказывает переполнение токенов
2. Сжимает контекст, сохраняя важную информацию
3. Выбирает более короткий промпт
4. Продолжает обрезанный ответ

#### Проблема: Высокие затраты на API
**Решение:** Система автоматически:
1. Кэширует повторные запросы
2. Оптимизирует промпты
3. Использует адаптивные лимиты
4. Сжимает контекст

#### Проблема: Медленные ответы
**Решение:** Система автоматически:
1. Использует кэш для быстрых ответов
2. Оптимизирует промпты
3. Адаптирует лимиты токенов
4. Сжимает контекст

### 🔧 Настройка

#### Конфигурация токенов:
```python
# В src/core/config.py
MAX_TOKENS = 4000          # Максимальные токены
CONTEXT_WINDOW = 3000      # Окно контекста
RESPONSE_TOKENS = 1000     # Резерв для ответа
MIN_TOKENS = 100           # Минимальные токены
```

#### Настройка кэша:
```python
CACHE_TTL = 3600           # Время жизни кэша (секунды)
CACHE_SIZE = 1000          # Размер кэша (записи)
```

#### Настройка мониторинга:
```python
MONITORING_ENABLED = True   # Включить мониторинг
AUTO_OPTIMIZATION = True    # Автоматическая оптимизация
```
