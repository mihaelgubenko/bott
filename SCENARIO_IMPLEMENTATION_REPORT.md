# Отчет о реализации разделения бота на сценарии

## 🎯 Цель проекта
Разделить HR-психоаналитика бота на два независимых сценария:
1. **Психологическая консультация** - для вопросов о снах, стрессе, отношениях, эмоциях
2. **HR-консультирование** - для вопросов о карьере, работе, профессии, обучении

## ✅ Выполненные задачи

### 1. Анализ текущей структуры
- Изучена архитектура бота и система промптов
- Проанализированы модули A/B тестирования и анализа настроений
- Определены точки интеграции для разделения сценариев

### 2. Создание системы определения сценариев
- **Расширены ключевые слова** для психологических запросов:
  - Сны, кошмары, проблемы со сном
  - Депрессия, тревога, стресс, паника
  - Отношения, семья, эмоции, чувства
  - Психологическая помощь, поддержка

- **Расширены ключевые слова** для карьерных запросов:
  - Работа, карьера, профессия, трудоустройство
  - Резюме, собеседование, HR консультация
  - Обучение, курсы, развитие навыков
  - Смена карьеры, выбор профессии

- **Добавлен параметр `scenario`** в функцию `analyze_speech_patterns()`:
  - `'psychology'` - для психологических запросов
  - `'career'` - для карьерных запросов  
  - `'general'` - для неопределенных случаев

### 3. Обновление промптов
- **Экспресс-анализ** теперь работает только для HR-сценария
- **Психологическая консультация** фокусируется на эмоциональной поддержке
- Обновлены промпты в модуле A/B тестирования
- Добавлена специализация ролей в промптах

### 4. Изменение логики анализа
- **Экспресс-анализ** запускается только при `patterns['scenario'] == 'career'`
- **Психологическая консультация** активируется для `patterns['scenario'] == 'psychology'`
- Адаптивные вопросы в зависимости от сценария
- Обновлена логика определения роли ИИ

### 5. Тестирование системы
- Создан тестовый скрипт `simple_test.py`
- Протестировано 13 различных сценариев
- **Результат: 100% тестов пройдено успешно**

## 🎯 Как работает система

### Автоматическое определение сценария:
1. **Пользователь пишет сообщение**
2. **Система анализирует ключевые слова**
3. **Определяется сценарий**:
   - Психологические слова → `psychology`
   - Карьерные слова → `career`
   - Нет ключевых слов → `general`

### Поведение бота по сценариям:

#### Психологический сценарий (`psychology`):
- Активируется психологическая консультация
- Фокус на эмоциональной поддержке
- НЕ предоставляется экспресс-анализ
- Адаптивные психологические вопросы

#### Карьерный сценарий (`career`):
- Активируется HR-консультирование
- Фокус на профессиональном развитии
- Предоставляется экспресс-анализ после 10 сообщений
- Адаптивные карьерные вопросы

#### Общий сценарий (`general`):
- Универсальные вопросы
- Ожидание уточнения потребностей
- Возможность перехода в любой сценарий
